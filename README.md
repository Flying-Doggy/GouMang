## Usage Example

### Step1. Get Pairwise Anchors

GouMang Framework relies on the collinearity results generated by [JCVI](https://github.com/tanghaibao/jcvi)

Before running the framework, ensure that your genome sequence files and annotation files are properly formatted according to [JCVI requirements](https://github.com/tanghaibao/jcvi/wiki/MCscan-(Python-version)).

Once your sequence (`.pep` or `.cds`) files and corresponding BED files are paired in the same directory, you can run the following command to generate all pairwise anchors:
`python anchors.py test/genome_dir --anchors-dir test/genome_dir/anchors/`

Here, you can also adjust the JCVI run using the following optional parameters:

```text
# JCVI options
--jcvi-args JCVI_ARGS      Additional JCVI parameters, e.g., "--no_dotplot --no_strip_names"
--cpus CPUS                 Number of CPUs allocated for JCVI execution
--dbtype {prot,cds}         Database type for JCVI (protein or coding sequences)

# Execution
--parallel PARALLEL         Number of target species groups to process in parallel
--keep-intermediates        Retain intermediate JCVI database files
--dry-run                   Print planned commands without actually running JCVI

# Logging
--log-file LOG_FILE          Path to save the log file
```

### Step2. Genome Segementation

Use the script `split_lineage_chromosomes.py` to divide each chromosome into distinct genomic segments.
These segments represent ancestrally conserved lineage blocks, derived from the collinearity relationships identified in Step 1.

```shell
python src/split_lineage_chromsomes.py  --anchors_dir test/genome_dir/anchors/ \
    --bed_dir test/genome_dir/ \
    --output_dir test/splitted
```

The output contains:

- `insulation_scores.csv` – Calculated insulation scores (IS) for all genomic windows.
- `chromosome_splits.csv` – Start, end, and additional metadata for each segmented genomic region.
- `threshold_evaluation.csv` – Evaluation metrics for different insulation score thresholds across all chromosomes.
- `collinear_blocks.csv` – Merged and extracted collinear blocks derived from all .anchors files.

Each of these files contributes to identifying and quantifying conserved genomic structures, forming the foundation for subsequent lineage reconstruction and comparative genomic analysis.

### Step3. Convert Segments Based on Orthologues

To cluster segments from different genomes, it's necessary to align all genes. Here, we use `orthofinder` to get orthogroups for all genes. Thus, you need to provide a gene matrix like orthofinder output:

```text
    TAXON-A  TAXON-B ...
G_α Aα1, Aα2   Bα1 ...
G_β   Aβ1     Bβ1 ...
...
```
